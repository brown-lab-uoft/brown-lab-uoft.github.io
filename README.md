# Brown Lab at UofT — Website

Academic website for the **Brown Lab** at the University of Toronto, led by **Joseph S. Brown** (Assistant Professor, Leslie Dan Faculty of Pharmacy).

Research focus: self-driving laboratories for peptide drug discovery, affinity-selection mass spectrometry (AS-MS), and active learning for molecular design.

**Live site:** [brown-lab-uoft.github.io](https://brown-lab-uoft.github.io)

---

Built with [Jekyll](https://jekyllrb.com/) using the [sbryngelson/academic-website-template](https://github.com/sbryngelson/academic-website-template).
Publications are managed via BibTeX (`assets/ref.bib`) and rendered with [jekyll-scholar](https://github.com/inukshuk/jekyll-scholar).
